# This project aims to solve sudoku's

Techniques used :-
- [Hidden Single](https://www.sudoku9x9.com/techniques/hiddensingle/){:target="_blank"}
- [Naked single](https://www.sudoku9x9.com/techniques/nakedsingle/){:target="_blank"}
- [Locked candidates](https://www.sudoku9x9.com/techniques/lockedcandidates/){:target="_blank"}
- [Naked pair](https://www.sudoku9x9.com/techniques/nakedpair/){:target="_blank"}
- [Hidden pair](https://www.sudoku9x9.com/techniques/hiddenpair/){:target="_blank"}
- [X-wing](https://www.sudoku9x9.com/techniques/xwing/){:target="_blank"}

The dataset has been taken from <https://projecteuler.net/problem=96>

You can run this app at [https://varun-sudoku-solver.streamlit.app/](https://varun-sudoku-solver.streamlit.app/)
