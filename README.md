# This project aims to solve sudoku's

Techniques used :-
- [Hidden Single](https://www.sudoku9x9.com/techniques/hiddensingle/)
- [Naked single](https://www.sudoku9x9.com/techniques/nakedsingle/)
- [Locked candidates](https://www.sudoku9x9.com/techniques/lockedcandidates/)
- [Naked pair](https://www.sudoku9x9.com/techniques/nakedpair/)
- [Hidden pair](https://www.sudoku9x9.com/techniques/hiddenpair/)
- [X-wing](https://www.sudoku9x9.com/techniques/xwing/)

The original question and dataset is available at <https://projecteuler.net/problem=96>

You can run this app at [https://varun-sudoku-solver.streamlit.app/](https://varun-sudoku-solver.streamlit.app/)
